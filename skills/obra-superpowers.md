## 1. 개요 (Overview)
`superpowers`는 AI 코딩 에이전트가 실제 사람 수준의 엔지니어링 규율을 지키며 개발할 수 있도록 돕는 실증적 스킬 프레임워크입니다. 단순 코드 생성이 아니라 테스트 작성, 에러 분석, 깃 커밋 관리까지 에이전트에게 '초능력(Superpowers)'을 부여합니다.

## 2. 주요 구성 (Features)
- **Test-Driven Agent Loops**: 에이전트가 코드를 작성하기 전에 실패하는 테스트 케이스를 먼저 작성하도록 강제하는 스킬 파이프라인.
- **Architectural Guardrails**: 기존 프로젝트의 아키텍처 규칙과 린트(Lint) 규칙을 위반하지 않도록 사후 검증 단계 내장.
- **Self-Healing Debugger**: 빌드 에러나 테스트 실패 시 에러 로그를 역추적하여 최소 단위 수정을 시도하는 복구 스킬.
