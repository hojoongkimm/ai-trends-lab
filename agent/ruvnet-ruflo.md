## 1. 개요 (Overview)
`ruflo`는 다중 지능형 에이전트(Multi-player Swarms)를 배포하고 복잡한 자율 워크플로우를 조율하는 종합 에이전트 하네스 플랫폼입니다. 단일 에이전트의 한계를 넘어 역할이 분화된 에이전트 간의 협업 프로토콜을 제공합니다.

## 2. 핵심 아키텍처 (Architecture)
1. **Adaptive Memory & Self-Learning**:
   - 에이전트가 수행한 작업의 성공/실패 경로를 벡터 DB에 인덱싱하여 다음 태스크 시 반성(Reflection) 및 자체 개선 반영.
2. **Multi-Agent Swarm Federation**:
   - 기획자, 개발자, 테스터, 리뷰어 등 독립된 역할을 맡은 서브에이전트들이 메시지 버스를 통해 병렬로 협업.
3. **Enterprise Integration**:
   - Claude Code, Hermes, OpenAI Assistant API 등 최신 프론티어 모델과 네이티브 연동.
