# ⚙️ OpenHuman: Fast, Cheap & Efficient Open-Source Agent Harness

---

## 1. 개요 (Overview)
`OpenHuman`은 월 $10 수준의 저사양 가상 서버(VPS)에서도 500개 이상의 백그라운드 자율 에이전트를 동시에 구동할 수 있도록 극단적으로 리소스를 경량화한 차세대 에이전트 하네스입니다.

## 2. 혁신적 특징 (Key Innovations)
- **Micro-Process Virtualization**: 각 에이전트의 런타임 메모리 풋프린트를 수 메가바이트(MB) 수준으로 압축.
- **Asynchronous Task Scheduler**: I/O 바운드 작업(웹 크롤링, API 폴링, 데이터 파싱)을 비동기 이벤트 루프로 처리하여 CPU 낭비 방지.
- **Serverless-Ready**: 도커 컨테이너나 쿠버네티스 없이도 독립형 바이너리로 어디서나 즉시 배포 가능.
